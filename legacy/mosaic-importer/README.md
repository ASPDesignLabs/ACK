# Mosaic Importer (parked)

`index.html` here is the browser-side half of an abandoned visual data
importer: it renders a 16-color noise grid with corner fiducial markers so a
phone camera could optically scan it back in, paired with
[`MosaicScannerActivity.kt`](../../app/src/main/java/com/example/besu/MosaicScannerActivity.kt)
on the Android side.

It's inactive — parked here rather than deleted so the history and approach
aren't lost. It previously lived at the repo root as `index.html`, which is
now the ACK project's GitHub Pages landing page instead.
