Augmented Communications Link — ACK

A Modern Approach to AAC, with a twist

Compose statements, build out context-based replies, utilize variables to speed up construction of statements. Use tap based controls to start playback or use the companion Wear OS app to unlock gesture based initiation. Created primarily to assist myself with situational mutism concerns. This covers the many moments throughout my day where communicating with others via non-verbal means is significantly easier. This tool is a fair bit more advanced than what you'd normally call AAC. The depth of statement construction, the ability to bridge statements, establish replies around specific contexts. You should not assume this is meant for someone with heavily limited communication and cognitive ability.

Built by one person, primarily to work around situational mutism — the moments where speaking out loud is much harder than it should be. I am not a speech-language pathologist, a mental health professional, or anyone with formal training in AAC design. Created entirely by myself to help address this gap. Do not use as a substitute for appropriate care and support from a qualified professional.

DUST WARNING This is a genuine dogfood-style experience. As I build out features I trial them in a testing environnment then integrate them into my daily life. I will limit this as much as I can with anything on main. Some bugs might sneak their way through though, so do make sure you are reviewing any changes as ACK is developed.

How it works

Multimodal Output

Tap controls

Like any AAC app or device there are easy to access tap shortcuts that can be used to initiate playback. This interface is where you will compose your replies and statements, use variable construction to make rapid edits to more formal communication, and build response and reply profiles around various forms of context.

Gesture playback

The Wear OS companion handles gestures using a simple state machine — ARM → LOCK POSE → MODIFY → FIRE — giving you the ability to trigger a configured prompt using your wrist. this works with the phone locked and the screen off.

Full-screen output

Prompts play back full-screen with visual and audible output together, with audio routing to either the phone speaker or a connected Bluetooth speaker.

Relying on being heard isn't always possible, or even permissible. Sometimes you want communications to be silent while offering a visual prompt for communication. If you want to prevent all voice output toggle 'Silent Mode' under PROTOCOL from any deck.

Decks

Organization with a focus on utility

A deck offers one specific form of organization of communication profiles on screen at any time, to make working with the greater context system easier with continuous use. MATRIX decks support the use of profiles which gives decks additional flexibility. Configure a deck around work related activities, along with a few profiles for more detailed work related tasks.

Decks aren't fixed. Tap the DECK label to create a new Quick Actions, Emergency, Emoji, or GIF deck — pick a type, name it, choose a color, done. MANAGE handles renaming, recoloring, or removing anything you've created.

MATRIX Deck

This is the core ACK deck and experience. Build around rapid statement creation and recall. Tap to initiate playback, edit a prompt, use variables to speed up construction. Prompts can be bound to one of the three poses used by the Wear OS experience, with up to four commands issuable per pose. Additional context poses can be added inside a MATRIX deck, allowing for hot-swapping of all replies under a pose with a single tap.

Quick Actions Deck

A more slimmed down experience that offers the user the ability to bind up to four phrases to a pose under a single form of context. Used for greetings, closures, quick references. Edit all three poses then initiate playback using the watch or with a tap.

Emergency Deck

Your high priority communications deck. If you need help, if you have a response script for when things become extra difficult, if you don't want your prompt to disapear due to a stray tap or clench, this is where you access these prompts. Prompts issued from here can include a beaconing tone that plays before a prompt is issued, increasing the likelihood of reception by others.

Never worry about an Emergency deck response leaving your screen without your intention. All Emergency deck prompts now remain on the screen until explicitly cleared with a long tap-and-hold interaction.

Emoji Deck

Emotional context can be difficult to deliver sometimes. This deck covers this a bit. Pick from a suite of emoji from the built-in library or use any emoji you have access to on your device. Group them by category, add text to the displayed prompt, make the emoji prompt more sticky.

GIF Deck

Memes. A powerful communication medium online, now ready to use in real space. Store and organize GIFs that you'd like to play at any time here. Modifiers for GIF prompts enable better display of different aspect ratio content. Add in text to your GIF prompt to reduce load on the recipient.

Manual Override

A standard textbox input that can be used to store phrases and prompts to a category of your choosing. These can be played with a quick tap. You can also use this to issue an ephemeral reply, if the message isn't worth saving.

Target Computer

Eight "targets" for any prompt you issue using ACK. These can be configured to prepend or append any simple prompt issued via a MATRIX or Quick Actions deck. Add a quick name, place, identity, or callout with a quick tap before issuing a prompt to see it added to your statement.

Audio Architect

Audio Architect splits into two layers. Global Output settings shape ACK's speech no matter which voice is active — Master Gain for volume, Global Cadence for dynamic pacing (letting output speed up and slow down through a phrase rather than reading at one flat rate), Force Speaker for routing, and Guide Vox to toggle spoken tutorial guidance on or off.

Voice itself comes from either a locked factory preset for a ready-to-use, consistent sound, or one of three fully editable custom slots. Each custom slot has its own DSP chain: pick a base voice from any TTS engine installed on your device, then shape it with pitch, a constant per-voice speed, an optional robotic overlay, and a bitcrush texture — save it, and it becomes a reusable voice of your own.

Variables & Root Overrides

Any phrase can hold a variable — write {VAR} in the Live Save Editor and ACK prompts for that value, or tag it {VAR:A}, {VAR:B}, or {VAR:C} to make it targeted instead of just local. A targeted variable can be bridged: turn on that tag's Root Override for a category, set one value, and it replaces that variable across every phrase in the category — no editing each one by hand. Think of a routine work task: tag the parts that actually change, like a name or a location, and one Root Override update carries across the whole deck. Root Override is entirely opt-in — every phrase already works on its own local value without it.

Training & confidence-building

Practice the gestures before you need them.

Training Ground

Free-form gesture practice with live telemetry and normal pacing — nothing you do here actually plays back or sends output. A safe space to get the arm/lock/modify/fire cycle into muscle memory.

Deck Trainer

Scored practice against your own real Matrix or Quick Actions deck, so you're rehearsing the actual layout you'll use — not a generic demo.

The companion

A Wear OS app that does the physical half.

Pairing & Sync

The watch side is deliberately small: it's what senses the pose, watches for a wake gesture (by default, a triple wrist twist so commands can't fire by accident), and pushes that event to the phone. The phone stays in charge of decks, profiles, and playback. A background sensor service on the watch keeps this working without needing the watch screen to stay open the entire time you're wearing it.

There's no separate pairing step — install ACK on your watch and phone, and as long as the two are already paired through Wear OS, commands start firing the moment the watch app is running. Under the hood it rides Google's Wearable Data Layer for that phone ↔ watch link.

Safety & Recovery

Fail-safes for stray taps, shaky hands, and messages that clear too soon.

Having the ability to recover from a misfire or accidental tap, interruptions, and moments where accuracy takes a hit are what make an assistive tool truly useful. A graceful method to play back a previously issued statement, a phone gesture to cancel playback of any prompt, and an additional way to cancel a prompt before it even leaves your watch.

These features help build confidence knowing there are ways to stop a statement you didn't want to say from being received, allowing playback from historical statements, and the ability to replay any visual prompt indefinitely.

Shake Kill Switch

You need multiple ways to stop a bad tap, gesture recognition, or statement from leaving your device or completing. One of these methods is a 'Shake to cancel' service that cancels any queued prompt or state traversal on the watch by shaking the phone. Configure sensitivity and test the configuration under PROTOCOL from any deck.

Shaky-Hands Mode

There are moments throughout a day that accuracy might take a hit. You might struggle to continuously trigger the poses you've practiced, you shouldn't be denied access to your tool when this happens. A new 'Shaky hands' mode increases the time needed to navigate through the ACK Wear state machine, with enhancements to addressing a set of noisy sensors due to a glitch in coordination. These options can be configured from any deck under PROTOCOL.

Enable 'Shaky Hands' mode anywhere in ACK Wear with a tap-and-hold interaction. This does increase the amount of time needed to confirm a pose command, you can always test this method out in the Training Grounds.

A way out before it fires

Misfires happen. Sometimes a pose isn't recognized properly for a host of reasons. You can always halt playback of these erroneous replies by tapping anywhere within ACK Wear to clear the current progression through the state machine, preventing the error from leaking through.

REPLAY: bring back what you missed

Issuing a prompt doesn't always land on first play. Things can prevent others from reading or hearing them, distractions happen, the situation at work can evolve at a rapid pace. You should have a little security here when it comes to managing this type of interaction. For a prompt that you just issued a 'replay' button will remain on your screen for twenty seconds after a visual prompt is cleared. Any prompt issued using 'replay' is sticky, they retain their presence on your screen until you tap to clear them.

The Terminal (logs) screen can be used to reissue any previously played prompt from any deck as well.

Help, onboarding & transparency

A tutorial system that only advances when you actually do the thing.

ACK's in-app help isn't a slideshow. Each module only steps forward when a real event fires from the real UI — a specific tap, a committed text field, a cleared overlay, an actual watch gesture broadcast — so finishing a walkthrough means you've genuinely done it once, not just read about it.

Your Data, Your Rules

Backup and restore live under Settings. Your decks, profiles, configurations, personification, and variables are yours — the Data Port exists so you can move them, keep copies, and never be locked into a single install.

Terminal

Every system, output, and watch event gets a timestamped, color-coded line in the Terminal — what ACK received, resolved, and sent. Any line that's an actual spoken phrase gets a replay control, and replaying an Emergency message keeps its safety behavior intact: forced speaker output, no auto-clear. The log lives in memory only — closing and reopening ACK clears it.

Under the hood

For anyone who wants to build it themselves.

ACK is Kotlin + Jetpack Compose, split into a phone module and a Wear OS module. Maps are rendered fully offline with Mapsforge/vtm — no tile server, no network dependency, matching the rest of the app's local-first design.

Build requirements

  • Android Studio

No region map ships with the app or the build — Geo-Protocol works by coordinate with no map data at all. Import your own Mapsforge-compatible .map file from inside the app (Geo-Protocol → Map Data → Import Map File) any time after install, no rebuild required. A personal build can still drop a splice into app/src/main/assets/tactical_grid.map as a build-time default if you'd rather bundle one.

Full contribution workflow — branch naming, commit conventions, and the day-to-day git flow — is documented in docs/GIT_WORKFLOW.md.
